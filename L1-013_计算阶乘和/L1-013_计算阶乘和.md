# L1-013 - 计算阶乘和（10 分）

- **时间限制**: 400 ms
- **内存限制**: 65536 KB
- **代码长度限制**: 16 KB

---

## 题目描述


对于给定的正整数$$N$$，需要你计算 $$S = 1! + 2! + 3! + ... + N!$$。

### 输入格式:

输入在一行中给出一个不超过10的正整数$$N$$。

### 输出格式:

在一行中输出$$S$$的值。

### 输入样例:
```in
3
```

### 输出样例:
```out
9
```

## 示例

### 示例 1

**输入:**
```
3
```

**输出:**
```
9
```
