# 团队程序设计天梯赛（GPLT）仓颉语言题解

这是 PTA 团队程序设计天梯赛练习集（GPLT）的仓颉语言题解文档，共 225 道题：

- L1 基础级：120 题
- L2 进阶级：60 题
- L3 挑战级：45 题

点击左侧导航即可按难度浏览全部题目。侧栏覆盖每一篇题解的完整标题，也可以使用顶部搜索框按题号、标题或关键词检索。

## 在线阅读

本站由 Docsify 驱动，通过 GitHub Pages 自动部署。页面右下角的按钮可以切换亮色/暗黑模式，选择会保存在当前浏览器中。

## 本地预览

```bash
python3 -m http.server 8899
```

然后访问 <http://127.0.0.1:8899/>。

## 目录说明

题解 Markdown 文件按 `Lx-题号_题目名.md` 命名并集中存放在仓库根目录。`scripts/generate_sidebar.py` 会读取这些文件的一级标题，生成 Docsify 使用的 `_sidebar.md`。
