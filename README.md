## 📖 项目简介

本仓库系统整理了 PTA 团队程序设计天梯赛练习集（GPLT）的 **仓颉（Cangjie）语言** 题解，适合：

- 正在学习 **仓颉语言** 的初学者，对照 GPLT 题目边练边学
- 已熟悉 C/Python 的同学，快速了解仓颉在 **IO、字符串、集合、图论、动态规划** 上的写法差异
- 需要 **PTA 天梯赛 / 团队赛** 备赛与复盘的同学，代码均按题目输入输出格式严格实现
- 想系统刷完 **L1 → L2 → L3** 进阶路径、查漏补缺的同学

每篇题解均包含：

- **前言** — 考点与分值一句话概括（GPLT 每题 5~30 分不等）
- **题目描述 / 输入输出格式 / 样例**
- **解题思路** — 分步骤讲清关键推导与复杂度
- **完整代码** — `cangjie` 代码块，可直接 `cjc run`，附详细注释

> 代码风格统一：`import std.console.* / std.convert.*` 处理输入，工具函数单职责，`main` 只做 IO 与调用。L2/L3 涉及图、堆、并查集、DP 等均封装为可复用模板。
