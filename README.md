## 📖 项目简介

**团体程序设计天梯赛（GPLT）** 是面向高校的程序设计竞赛，题目按难度分为三级：

- **L1 - 基础级（5-20 分）**：语法、模拟、字符串、简单数学，适合入门
- **L2 - 进阶级（25 分）**：数据结构与算法（图、树、并查集、堆、DP、贪心等）
- **L3 - 挑战级（30 分）**：综合难题（最短路变体、网络流、复杂 DP、几何等）

本仓库使用 **华为仓颉语言（Cangjie）** 实现全部 225 题，每题独立目录，包含可直接运行的仓颉源码与结构化题解文档，并内置 **Docsify 静态站点**（`index.html` + GitHub Pages 自动部署），适合：

- 仓颉语言入门与进阶，对照 GPLT 题目边练边学
- 已熟悉 C/Python 的同学，快速掌握仓颉在 **IO、字符串、集合、图论、动态规划** 上的写法差异
- 天梯赛 / 团队赛备赛与复盘，代码均按 PTA 输入输出格式严格实现
- 系统刷完 **L1 → L2 → L3** 进阶路径、查漏补缺

> **范围声明**：本 README 仅描述当前仓库 `仓颉语言实现/` 内的 225 个题目目录、配套 `*.cj` / `*.md` 文件及 Docsify 站点相关文件（`index.html / .nojekyll / .github/workflows/pages.yml`），不包含父目录或其他语言版本。

## ✨ 仓库特点

| 特性 | 说明 |
|------|------|
| **一题一目录** | `Lx-yyy_题目名/` 独立目录，命名与 PTA 题号严格一致 |
| **一题两文件** | 每题均含 `.cj` 仓颉源码 + `.md` 题解，互为补充 |
| **注释详尽** | `.cj` 文件头部含题号、分值、题目描述、实现原理；行内关键步骤均有中文注释 |
| **文档完整** | `.md` 含题目描述、输入/输出格式、样例、解题思路、复杂度分析、代码实现 |
| **原生仓颉** | 仅依赖 `std.console / std.collection / std.convert / std.math / std.env` 等标准库，`cjc` 可直接编译运行 |
| **Docsify 站点** | 根目录 `index.html` 为 Docsify 入口，支持侧边栏、搜索、分页、深色模式，开箱即 GitHub Pages |
| **全量覆盖** | L1 120 题 + L2 60 题 + L3 45 题 = **225 题** 全覆盖 |

### 单题目录规范

以 `L1-001_Hello_World/` 为例：

```
L1-001_Hello_World/
├── L1-001_Hello_World.cj   # 头部注释 + import std.console.* + main() { println(...) }
└── L1-001_Hello_World.md   # 标题、分值、时空限制、题目描述、输入输出、样例、解题思路、代码实现
```

所有题目目录均遵循此两文件结构，文件名与目录名保持一致，便于脚本批量处理与 Docsify 侧边栏自动生成。

## 🛠️ 常见问题

**Q: 仓颉的输入为什么都用 `readToEnd` 再切分？**  
A: PTA 输入可能含多行、空行与多空格，统一按 `Rune` 空白切分 `tokens` 再 `Int64.parse` 解析最稳健，已在 L1-015 等题中验证容错性。

**Q: 为什么大量使用 `ArrayList/HashMap` 而非原生数组？**  
A: 仓颉标准库以 `ArrayList<T>` / `HashMap<K,V>` 为通用容器，支持动态扩容与泛型，竞赛题中更灵活；定长场景亦可使用 `Array<T>`。

**Q: `Option` 与 `??` 是什么？**  
A: `readToEnd()` 返回 `Option<String>`，用 `?? ""` 提供默认值避免空指针；`trimAscii().isEmpty()` 判空后直接 `return` 是常见的空输入保护。

**Q: 如何切换深色模式？**  
A: 站点右下角悬浮按钮（🌙/☀️）即为 `darklight` 切换，基于 `docsify-darklight-theme`，自动记忆偏好。
